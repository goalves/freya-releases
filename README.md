# Freya

Release builds of the Freya client and launcher for Windows, macOS and Linux.

Download the launcher for your platform from the
[Releases page](../../releases/latest) and run it. It installs and updates
the client for you. Playing requires a Ragnarok Online `data.grf` you already
own.

Proprietary, all rights reserved. Binaries are provided for play on a private
server.
